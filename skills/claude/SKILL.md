# Start here

The skills in this repo (claude-skills) are one small skill per concern. Each header carries `priority`, `tags`
(hashtags) and `requires` (what it needs: other skills, commands, libraries, MCP servers...). The standard and the
tooling are in `skill-everything`.

## How to use them

1. Now: load every priority-0 skill below. They are short and apply to everything.
2. When a task starts: match its words and its hashtags against the list (or `bin/skills ls '#tag'` in the repo) and
   load the matching priority-1 and priority-2 skills. Priority 3 only when the user names it.
3. Load what a skill `requires` (`skill:` entries) along with it. `bin/skills req NAME` checks the
   commands, libraries and servers too; a missing optional (`?`) one means use its fallback.
4. Two skills disagree: the lower priority number wins. The user's explicit instruction in the session and a repo's own
   CLAUDE.md beat every skill.
5. A lesson worth keeping comes up: add it to its skill or make a new one (`skill-everything`).

Where they load from: `~/.claude/skills` (linked by `bin/skills install`); in a cloud session with this repo attached,
its `.claude/skills`; otherwise clone the repo and read `skills/`.
