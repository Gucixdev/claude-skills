# Research

## Prefer primary sources

- Official docs, man pages, source code over secondhand summaries or training-data recall -
  same root habit as the `code (done)` part, applied to the web instead of a local `--help`.
- For ML datasets specifically: HF-mirror-style sources, see the `reference_data_sources`
  memory for his usual ones.
- Never guess a URL - only follow one he gave, or one a search tool actually returned.

## WebSearch: standard vs extended

- Standard first for anything routine.
- Extended when standard comes back thin, off-target, or stale - or up front for fast-moving
  topics (prices, releases, recent events) and niche facts unlikely to be well-indexed.

## When a plain fetch isn't enough

Default path is WebSearch/WebFetch - no interactive browser needed to read a page. Only reach
for an actual browser-driving tool (if one is available this session) when a source needs real
rendering or a login a plain fetch can't get past. Never his own GUI Firefox for this - see
`machine (firefox)`; a disposable/automated browser session is fine, his daily-driver window
isn't.

## Reporting back

Cite findings the way `code (caveman)` asks for prose generally: the fact, the source named inline,
no padding - not a pasted wall of the page.

## Related skills

- verify - same "primary source over memory" habit, for commands instead of facts.
- firefox - his real browser profile; never touch or launch it mid-research.
- caveman - keep the write-up terse and dense once research is done.
