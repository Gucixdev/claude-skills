# skills/factory

The skill factory's own folder: one skill per lasting lesson of a session, made by `bin/skills factory` (the digest)
and the session after it. His skills elsewhere are not edited by the factory; he moves a factory skill out (with
`git mv`) when he wants it among them, or merges it. Each skill here: `factory-NAME/SKILL.md`, priority 2, the tag
`#factory` beside its own tags, the session and date it came from in its body.
